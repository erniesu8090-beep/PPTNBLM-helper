# 🎬 CAST. Studio | NotebookLM 簡報限制突破與雙人口白對談提示詞主控台

> **專為 Google NotebookLM (NBLM) 量身打造的長簡報規劃、YAML 切割與雙人對話口白提示詞生成工具。**  
> 採用現代深色玻璃擬物風格 (Dark Glassmorphic UI) 設計，無需安裝任何伺服器或依賴庫，純靜態網頁開啟即用！

---

## 🌟 為什麼需要 CAST. Studio？

使用 **Google NotebookLM** 進行簡報生成與影片口白製作時，創作者常遇到以下兩大痛點：

1. **簡報單次生成頁數上限 (約 13-15 頁)**： NotebookLM 在單次對話中無法一次輸出 20 頁以上的長簡報。
2. **講解口白缺乏對話感與 TTS 語音合成崩潰問題**： 自動生成的雙人口白容易變成單向長篇大樓、缺乏「有來有往」的交流感；或因包含括號、引號、諧音字等導致 TTS 語音配音生成無聲或錯誤。

**CAST. Studio** 透過獨家的 **全域 YAML 規劃提示詞**、**智慧 YAML 切割器** 與 **雙人對談 prompt 引擎**，為您徹底解決這些難題！

---

## ✨ 核心功能亮點

### 📊 1. 簡報 15 頁限制突破 (Slide Helper & YAML Splitter)
* **全域 15-30+ 頁簡報規劃**：引導 NotebookLM 全盤評估筆記本來源，一口氣規劃出具備全域連貫性的 YAML 架構（不受 10 頁上限限制）。
* **簡報 YAML 智慧切割器**：複製完整 YAML 貼入，自動依 10 頁/12 頁上限切割為 `Part 1`、`Part 2` ... 並自動插入**風格錨點頁**與**過渡緩衝頁**。
* **PowerPoint 完美無損合併指引**：運用 PowerPoint 內建「重複使用投影片 (Reuse Slides)」與「保留來源格式 (Keep Source Formatting)」，10 秒無損拼接完美長簡報。

### 🎙️ 2. 雙人對話與講解口白腳本 (Slide Narrative & Dialogue Console)
* **雙發言模式切換**：支援 **`👤 單人獨白模式`** 與 **`🎙️ 雙人對談模式 (Host A & Guest B)`** 一鍵動態切換。
* **100% 遵照《雙人對話腳本格式指南》**：
  - **Speaker Tags 規範**：角色 A (主講人/Host) 發言標籤 `A:` / `A：`；角色 B (對談者/Guest) 發言標籤 `B:` / `B：`。
  - **換行分段書寫 (格式 B)**：完美對接「影片製作工坊」100% 自動匯入、字幕切分與雙人角色自動配音。
* **⚡ 頻繁有來有往 (Multi-Turn Exchange Engine)**：
  - 強制每一頁解說都包含 **2 至 4 個回合 (4~8 句) 的角色交替互動**（開場引題 ➔ 追問探討 ➔ 深入剖析 ➔ 歸納轉場）。
  - 融入真實對談連結詞（如「等等，專家您剛才提到...」、「這確實是很多人的痛點！」、「沒錯，但實務上該怎麼執行？」）。
* **🛡️ 語音合成防崩潰機制**：提示詞自動植入 TTS 穩定條款（禁用中英文括號、引號、標示星號與「雞排」等 jī pái 諧音字）。

### 🎨 3. 豐富預設模板 (Presets)
* **單人獨白**：工業技術培訓、科普教育教學、產品推廣商業、企業合規宣導、人生智慧哲理
* **雙人對談**：雙人理財對談 (Host A + 專家 B)、雙人技術專訪 (PM A + 架構師 B)、雙人生智慧哲理對談 (對談主持 A + 心靈導師 B)

## 🚀 快速開始 (Quick Start)

本專案為純靜態網頁（Pure Static HTML/CSS/JS），無需安裝 Node.js 或執行任何構建命令。

1. **複製本專案**：
   ```bash
   git clone https://github.com/your-username/NBLM-Slide-Console.git
   cd NBLM-Slide-Console
   ```
2. **開啟工具**：
   直接雙擊開啟 `index.html` 或 `prompt_helper.html` 即可在瀏覽器中使用！

## 📖 雙人對話腳本 Speaker Tags 規範速查

系統產出的對講提示詞會自動指示 AI 遵守以下格式，以確保腳本解析器 100% 自動匯入：

| 角色標籤 | 推薦寫法 | 其他可識別標籤 |
| :--- | :--- | :--- |
| **🔷 角色 A (主講人 / Host)** | `A:` 或 `A：` *(最推薦)* | `[A]`, `主持人:`, `Host:`, `甲:`, `角色A:` |
| **💜 角色 B (對談者 / Guest)** | `B:` 或 `B：` *(最推薦)* | `[B]`, `專家:`, `來賓:`, `Guest:`, `乙:`, `角色B:` |

### 建議寫法範例（換行分段書寫）：
```text
【第 1 頁：家庭資產配置與複利效應】
A: 各位好，歡迎來到今天的理財對談節目。今天我們要探討如何進行合理的資產配置。
B: 沒錯！資產配置是家庭財務安全的基石，我們可以看到這張圖表顯示...
A: 專家，您剛才提到這個關鍵點，那在實務上一般人最容易踩到什麼坑？
B: 這問得非常好！大家最容易忽略的是緊急預備金的留存比例...
A: 原來是這樣！那有沒有什麼好方法可以避免？
B: 只要記住『先存再刷』的原則，就能輕鬆踏出第一步。
```
